# Privacy and Source

## What this repository is
A portfolio showcase for a custom application. It describes the engineering; it is not a source distribution.

## Published
- Written descriptions of architecture, decisions and limits
- An original diagram
- Screenshots of a local build running on fictional demo data

## Not published
- Application source code
- Local databases and uploaded or generated media
- Environment files and any configuration

## Demo data
All farms, owners, fields and scans are fictional. Scan images are synthetic, generated programmatically; no real photos or personal data are used.

## Third-party assets
Chart.js is bundled for charts and Inter is loaded as a web font. Their names and licences belong to their owners. The app mark is a simple original SVG.
